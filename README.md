# 감귤 도매시장 7일 예측 대시보드

## 실행

1. 이 폴더를 압축 해제합니다.
2. `run_dashboard.bat`을 실행합니다. 또는 터미널에서 다음 명령을 사용합니다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

앱 실행 시에는 함께 제공되는 `rf_precomputed_forecasts.csv`를 읽어 화면에 표시합니다. 앱 실행 중 모델 학습이나 예측 계산은 하지 않습니다.

입력 CSV를 바꾸고 결과를 갱신할 때만 아래 명령을 순서대로 실행합니다. 첫 명령은 학습된 모델 파일을 만들고, 둘째 명령은 날짜·시장·품목별 예측 결과를 CSV로 저장합니다.

```powershell
python train_models.py
python precompute_forecasts.py
```

## 입력 데이터

- 기본 입력은 `kat_sale_citrus_part2.zip`의 `kat_sale_citrus_merged.csv` 집계입니다.
- 한라봉·천혜향은 제공된 69개 월별 `mkat_sale_citrus` 원자료에서 요청한 3·5·9kg 상자 거래를 추려 기본 저장 히스토리 CSV에 합쳤습니다. 원자료 집계본은 `rf_dashboard_supplement.csv`로도 보관합니다.
- 품목 선택에는 조생귤·한라봉·하우스감귤·천혜향 네 가지를 모두 유지합니다. 시장 선택은 주요 5개 시장 개별 선택과 함께 보기입니다.
- 모델과 예측 계산은 화면을 열기 전에 실행해 저장합니다. Streamlit 화면은 네 품목이 들어 있는 기본 히스토리 CSV와 저장된 예측 CSV를 읽어 보여줍니다.
- 상세 집계와 제외 기준은 `data_audit.md`, 파일별 입력 정보는 `data_manifest.json`에 있습니다.

## 예측 방식

- 거래량 RandomForest는 시장·품목·상자별 일 총량을 학습하며 거래가 없는 날짜는 0톤으로 포함합니다.
- 학습 시간과 저장 크기를 줄이기 위해 각 목표 변수에서 최대 120,000개 행을 고정 난수 시드로 표본 추출합니다.
- 가격 RandomForest는 날짜·시장·품목·상자·등급·크기별 원/kg 단가를 학습합니다.
- 등급과 크기 선택 없이 과거 같은 계절의 거래량 점유율을 반영해 전체 예측을 계산합니다.
- 시장 선택은 주요 5개 시장 개별 선택 또는 주요 5개 시장 함께 보기로 제한합니다.
- 개별 시장 비교에서는 선택 시장과 전체 시장에 모두 데이터가 있는 거래일만 표시하고, 함께 보기에서는 주요 5개 시장 모두에 데이터가 있는 거래일만 비교합니다.
- 날짜 선택은 오늘 기준 3일 전부터 3일 후까지입니다. 빠른 날짜 버튼은 오늘과 +7일입니다.
- 미래 예측은 전체 32개 시장으로 미리 계산한 CSV에서 가져옵니다. 이 파일은 생성일 기준 ±3일 선택 날짜와 +7일 빠른 날짜를 포함합니다.
- 선택 날짜가 실거래 기간이면 이후 거래일의 실적을, 미래 날짜이면 저장된 예측 결과를 표시합니다.
- 단가는 `totprc 합계 / unit_tot_qty 합계`; 상자 가격은 단가에 상자 중량을 곱합니다.
- 일요일, 정해 둔 공휴일, 과거 2개 연도 이상 출하 이력이 없는 주차는 예측 기간에서 건너뜁니다.

## 예측값과 참고 사이트 비교

이 패키지에는 Google Sites 참고 대시보드의 저장 모델, 학습 코드, 전처리 규칙이 들어 있지 않습니다. 따라서 같은 이름의 RandomForest를 사용해도 참고 사이트와 숫자가 같아지지는 않습니다. 제공된 거래 CSV로 모델을 학습하고 예측 결과를 미리 계산해 저장했습니다. 대시보드는 해당 저장 결과만 읽습니다.
